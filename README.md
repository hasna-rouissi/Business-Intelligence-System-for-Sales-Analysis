# Business-Intelligence-System-for-Sales-Analysis
A Business Intelligence project that builds a sales analysis system using a MySQL database, Talend ETL, a star-schema data warehouse, and Power BI dashboards. It delivers KPIs, dimensional analysis, and an end-to-end BI architecture.


## 📌 Objectives
- Build a DataMart for sales analytics.
- Define KPIs: total sales, number of products, clients, sales by region/category.
- Design a star schema (fact + dimensions).
- Implement an ETL pipeline with Talend.
- Create interactive dashboards in Power BI.

## 🏛️ Architecture
1. **Data Sources:** MySQL  
2. **ETL Layer:** Talend Open Studio  
3. **Data Warehouse:** MySQL (star schema)  
4. **Visualization:** Power BI  

## 🗂️ Technologies
- **MySQL Workbench** – Database & Data Warehouse  
- **Talend Open Studio** – ETL workflows  
- **Power BI** – Dashboarding & Data Visualization
